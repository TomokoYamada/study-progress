# 学習状況カードの要件定義

## 日報からの学習時間の取得

- 「今日行ったこと」の後ろにある括弧内の時間を、その日の学習時間として扱う。
- 時間はh単位で入力し、小数にも対応する。
- 数字・括弧・英字の全角と半角の混在を許容する。
- hとHの両方に対応する。
- 見出しと時間の間のスペース・改行・コロンなどを許容する。
- 見出しの前にある装飾記号には依存しない。
- 日報の本文に登場する時間は集計しない。
- 時間が読み取れない、または複数あって判断できない場合は、
  黙って0時間にせず、確認が必要なことを利用者に知らせる。

## 学習日の判定

- Slackの投稿日時をもとに学習日を決める。
- 1学習日は、当日の午前8時から翌日の午前8時直前までとする。
- 午前0時から午前8時未満の投稿は、前日の学習記録として扱う。
- 午前8時ちょうどの投稿は、当日の学習記録として扱う。
